Tratamiento de las variables

Tratamiento de las variables

Al tratarse de un aula específica con alumnado TEA, pueden aparecer variables que influyan en el desarrollo de las actividades y en los resultados obtenidos:

  • Diferencias en el nivel de comunicación oral.
  • Necesidad variable de apoyos visuales.
  • Fluctuaciones atencionales.
  • Intereses restringidos.
  • Dificultades de regulación emocional.
  • Distintos niveles de competencia digital.

Para garantizar una evaluación ajustada y equitativa:

  • Se valorará el progreso individual respecto al punto de partida de cada alumno.
  • Se flexibilizarán tiempos y formas de respuesta.
  • Se aceptarán diferentes modalidades de comunicación (oral, gestual, pictográfica o mediante SAAC).
  • Se registrará el nivel de ayuda necesario para completar cada tarea.
  • Se triangularán los datos obtenidos mediante los tres instrumentos (rúbrica, diana y registro anecdótico) para obtener una visión más completa del aprendizaje.

De este modo, la evaluación permitirá conocer tanto los logros alcanzados como las necesidades de apoyo que puedan surgir durante el proceso.
